# 1.1.0-beta.1 preparation

This branch prepares the declarative DI beta; it does not publish a release.

`#[cauldron(root, ...)]` checks constructor dependencies against local outputs, direct exported imports, reachable exported globals and intrinsic Config. Registration comes from the same existing attribute. Optional `#[inject]` markers work on managed fields; unmarked legacy fields and fluent cauldrons remain supported. DatabaseCauldron and LoggerCauldron now supply the contract across crates.

See the [API/migration guide](../declarative-di.md) and [executable example](../../example/compile-time-di/). The example's Cargo test confirms that removing LoggerCauldron fails compilation, even without starting the application.

Beta limits: module type aliases cannot be declarative imports (use aliases and re-exports work); imported legacy modules lack metadata; marked roots cannot be imported by other marked roots; expansion limits apply. Native override values do not remove static constructor requirements. Runtime preflight, configuration, I/O and lifecycle errors still require handling. These limits are documented without changing legacy fluent behavior.

The workspace and exact local dependency pins target 1.1.0-beta.1. PostgreSQL integration tests retain their existing opt-in external-service requirement; ordinary regressions use mocks.

See the [verification and TDD history](1.1.0-beta.1-verification.md) for checked commands, test results and external-service exclusions.
