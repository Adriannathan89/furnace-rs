# 2.0.0-beta.2 release notes

FURNACE 2.0.0-beta.2 adds native protobuf gRPC serving and client consumption. The release keeps the proto-first Tonic API and places gRPC in the standalone `furnace-rs-grpc` and `furnace-rs-grpc-macros` crates, with optional facade integration through `furnace-rs` features.

## gRPC services and clients

Applications own their `.proto` files, generated Tonic types, and descriptor bytes. Furnace registers generated service implementations through managed cauldrons and supports unary, server-streaming, client-streaming, and bidirectional-streaming RPCs. Named generated clients can be injected into application providers, with per-call credentials, asynchronous token providers, and establishment deadlines.

The example includes a vendored build-time protobuf compiler, a mixed HTTP/gRPC configuration, guarded RPCs, and runnable `grpcurl` requests for each RPC shape. The example also provides a local demo-token command for protected calls.

## Authentication, TLS, and runtime

gRPC admission shares Passport verification and policy contracts with HTTP. Service guards, public methods, replacement method guards, typed principals, and admission-time stream authentication are supported. Explicit Bearer credentials and token-provider results are marked sensitive for debug redaction and HTTP/2 never-indexed encoding.

TLS verifies server certificates and hostnames, supports source-relative identities and additive or isolated custom CA roots, and requires Rustls 0.23.46 or later. The runtime can select HTTP and gRPC together under one application graph and lifecycle, waits for eager client readiness before binding, exposes health and scoped reflection, and drains active calls before provider cleanup.

The CLI adds side-effect-free `furnace grpc` inspection and uses the existing doctor checks. Public JSON schema 2 remains unchanged; the private inspection handshake advances to 3.

## Using the gRPC facade

For a gRPC client or server through the facade, enable `grpc`; add `jwt` for Passport protection and `grpc-tls` for verified TLS:

```toml
[dependencies]
furnace-rs = { version = "=2.0.0-beta.2", default-features = false, features = ["grpc", "runtime-tokio"] }
```

See the [gRPC guide](../grpc.md), [transport example](../../example/grpc-transport/), and [workspace changelog](../../CHANGELOG.md) for configuration and API details.
