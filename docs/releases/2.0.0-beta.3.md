# 2.0.0-beta.3 release notes

FURNACE 2.0.0-beta.3 adds optional entity storage helpers and incorporates the
beta implementation review corrections. Rust 1.94 remains the minimum supported
compiler.

## Optional entity storage

`#[storage(entity = path::Entity)]` binds a repository to native SeaORM CRUD.
Connection selection is optional when one injected `DatabaseConnection` field
is unambiguous. Declared relations generate explicit native relation loaders.
Queries retain typed filters and explicit ascending or descending ordering.

`.paginate(page_number, page_size)` uses one-based page numbers and requires
explicit ordering. It loads exactly the requested parent page without a total
count or lookahead. Applications control size limits and transactions.

Enable `furnace-rs/sea-orm-storage` to propagate storage errors with `?` into a
redacted HTTP 500 response. Handlers can override individual mappings with
`.map_err(...)`. The new `furnace-rs-persistence-types` crate shares error
contracts without registering database connector providers.

See the [storage guide](../storage.md) and the independent
[storage CRUD example](../../example/posts-crud-storage/). The existing
[posts example](../../example/posts-crud/) continues to demonstrate ordinary
SeaORM access.

## Review corrections

This release includes conditional gRPC admission policy corrections, resumable
lifecycle cleanup, configuration merge and validation fixes, safer cookie
names, body-timeout response header preservation, and CLI Cargo configuration,
dynamic linking, and development watcher corrections. The original review and
the implemented review corrections are summarized in the
[changelog](../../CHANGELOG.md).
The gRPC policy before/after reproduction is in the
[benchmark security report](../../benchmark/SECURITY.md#f01-conditional-grpc-admission-policy).

The release review also corrected the shared storage crate's omission from
versioning, archive checks, and publication order; added beta publication
retries; synchronized independent example pins during release preparation;
and removed remaining yanked `yoke-derive` lock entries. Consumer tests prepare
their standalone dependencies in every workspace test job, and compiler
snapshots account for Rust 1.99 diagnostic changes.
The PostgreSQL jobs now execute the generated storage acceptance test as well
as the connector tests; the storage test had previously been left ignored.

## Installation

```toml
[dependencies]
furnace-rs = { version = "=2.0.0-beta.3", features = ["sea-orm-storage"] }
furnace-rs-persistence = { version = "=2.0.0-beta.3", features = ["sea-orm-storage", "sea-orm-postgres"] }
```

```sh
cargo install furnace-rs-cli --version 2.0.0-beta.3 --locked
```

See the [verification record](2.0.0-beta.3-verification.md) for this checkout's
review scope, findings, and validation limits.
